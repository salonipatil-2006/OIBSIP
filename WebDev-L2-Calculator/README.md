# 🧮 Professional Calculator

A modern, responsive, and interactive **browser-based calculator** developed as part of the **OASIS INFOBYTE Web Development & Designing Internship – Level 2, Task 1**.

The calculator provides a clean and user-friendly interface for performing basic arithmetic calculations.



## 📌 Project Overview

This project demonstrates the use of **HTML5, CSS3, and JavaScript** to create a functional calculator with a modern user interface.

The design focuses on simplicity, usability, responsiveness, and an attractive visual experience.



## ✨ Features

* ➕ Addition
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division
* % Modulo operation
* 🔢 Decimal number support
* 🧹 Clear button
* ⌫ Delete button
* 🟰 Equal button
* ⚡ Interactive button animations
* 📱 Responsive design
* 🌙 Modern dark premium interface
* ✨ Glassmorphism and gradient effects
* ⚠️ Handles division by zero

## 📂 Project Structure

```text
web_l2_task1_calculator/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

### `index.html`

Contains the structure of the calculator, including the display and calculator buttons.

### `style.css`

Contains the complete visual design, including:

* Premium dark theme
* Glassmorphism
* Gradients
* Button animations
* Responsive layout
* Hover and click effects

### `script.js`

Contains the calculator functionality and handles:

* Number input
* Arithmetic operations
* Decimal values
* Clear operation
* Delete operation
* Result calculation
* Division-by-zero handling



## 🎯 Objective

The objective of this project is to build a **fully functional browser-based calculator** with a user-friendly button interface and basic arithmetic operations.



## 🚀 How to Run

1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Use the calculator buttons to perform calculations.

No additional installation or server is required.
