# Dr. A. P. J. Abdul Kalam — Tribute Page

## OASIS INFOBYTE Web Development and Designing Internship

**Task:** Level 2 – Task 2: Tribute Page

## Project Overview

This project is a responsive tribute page dedicated to Dr. A. P. J. Abdul Kalam, one of India's most respected scientists, educators, authors, and former President.

The website presents his life journey, achievements, important milestones, inspirational thoughts, and lasting legacy through a clean and modern interface.

## Features

- Responsive design for desktop, tablet, and mobile
- Full-screen hero section
- Biography section
- Inspirational quote section
- Key achievements
- Life timeline
- Legacy section
- Smooth navigation
- Scroll reveal animations
- Hover effects
- Back-to-top button
- Mobile-friendly layout

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts
